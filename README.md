# فَنّك — مشروع تطبيق ترفيهي عربي

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ:
   `npm install`
4. شغّل:
   `npm start`
5. افتح `http://localhost:3000`

## لوحة التحكم
الرابط:
`http://localhost:3000/admin.html`

لإنشاء أول مشرف، شغّل السيرفر ثم أنشئ حساباً من التطبيق، وبعدها عدّل `role` للمستخدم إلى `admin` في `data/db.json` ثم سجّل الدخول للوحة التحكم.

## التثبيت على الهاتف
عند نشر المشروع على استضافة HTTPS، المتصفحات الداعمة ستعرض خيار تثبيت PWA. زر التثبيت داخل التطبيق يظهر عندما يتيح المتصفح ذلك.

## مهم قبل النشر العام
- غيّر `JWT_SECRET` إلى قيمة سرية قوية.
- استخدم HTTPS.
- انقل بيانات المستخدمين إلى قاعدة بيانات حقيقية عند زيادة عدد المستخدمين.
- أضف سياسة خصوصية وشروط استخدام ومراجعة أمنية قبل الإطلاق التجاري.
